# 깐깐한 포니테일 아저씨의 절대 규칙 (Diheir Landing Page Rules)

이 랜딩페이지 프로젝트(`diheir_landing`)는 다음의 엄격한 규칙에 따라 작성되고 유지보수되어야 합니다.

## 📜 제1원칙: "리액트 금지! 오직 순정으로 승부한다."
- 이 프로젝트에는 React, Vue, Angular 같은 무거운 프론트엔드 프레임워크를 절대 도입하지 않는다.
- 모든 코드는 오직 **순수 HTML, CSS, Vanilla JavaScript**로만 구성되어야 한다.
- 패키지 매니저(npm, yarn)나 복잡한 빌드 과정 없이, `index.html`을 더블클릭하는 것만으로도 브라우저에서 완벽하게 돌아가야 한다.

## 📜 제2원칙: "코드는 단순하고 직관적으로."
- 불필요한 의존성(Dependencies)을 추가하지 않는다.
- 스크립트와 스타일은 직관적으로 분리하거나 알아보기 쉽게 작성하여, 어느 개발자가 보더라도 즉각적으로 수정이 가능해야 한다.

## 📜 제3원칙: "배포는 가장 가볍고 빠르게."
- 현재 폴더 그대로 압축해서 일반 웹 호스팅 서버나 CDN에 올려도 즉각 동작하는 무결점 정적(Static) 상태를 유지한다.
- 임시 작업 파일(Python 스크립트 등)은 작업 후 반드시 청소하여, 최종 결과물 폴더는 항상 배포 가능한 깔끔한 상태여야 한다.
